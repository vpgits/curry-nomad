Why this, why now

Most "agent demos" teach the wrong half.

They wire up a chatbot and a tool call, then stop — skipping the things that actually separate a toy from a system: when to use an agent vs. a workflow, how to evaluate non-deterministic output, and how to see what the agent is doing. This case study leads with exactly those.

🎯

One codebase, both paradigms

THE CORE LESSON

Engineers leave knowing when to reach for an agent (open-ended, self-correcting) and when a workflow (predictable, multi-step) — because they see both side by side.

The two capabilities

Agent vs. workflow — shown, not asserted.

PATTERN · AGENTIC LOOP WITH SELF-CORRECTION

The model decides the path.

Open-ended questions over the business DB. The agent inspects the schema, writes SQL, runs it — and when a query fails, it reads the error and repairs it. This loop is the safe, reproducible answer to "why agents?".

01
agent (LLM + tools)
Reasons about the question, picks a tool.
02
tools: list_tables · describe_table · run_sql
Read-only by design — SELECT-only, enforced LIMIT, timeout.
↻
self-correct on error
run_sql returns the DB error as a tool result → the model fixes the query and retries.
03
answer
Interprets rows, applies remembered metric definitions, replies.

GATE BY RISK

No approval here.

Reads are safe, so they're not gated. That's the lesson: gate by risk, not reflexively. HITL lives where it matters — the workflow.

SQLiteToolNodeconditional edgesground-truth evals

PATTERN · CHAINING · EVALUATOR-OPTIMIZER · PARALLELIZATION

A predictable pipeline → a video-ad creative brief.

Grounded in the chosen product's real data. Produces a structured VideoBrief: concept, 30s script, shot list, and per-scene text-to-video prompts.

01
fetch_product
Pull facts from SQLite (origin, price, category).
02
ideate_concepts ∥
2–3 concept options generated in parallel.
03
write_script
Compose a ~30s script with timed beats.
⏸
human review (interrupt) — HITL
Approve or edit the script before compute is spent on shots/render.
04
storyboard → shot_prompts ∥
Break into shots; per-shot text-to-video prompts in parallel.
05
critique → revise ↻
Evaluator checks brand voice + platform rules (hook in 3s, CTA, duration); optimizer revises until it passes.
06
assemble VideoBrief · [render adapter]
Structured output. Rendering is an optional swap — fake by default.

HITL AS A CHECKPOINT

Review mid-pipeline.

Not a final "are you sure?" — a real review gate inside the flow, the most common production HITL shape.

The headline · Evaluation

Two kinds of evaluation, taught in contrast.

Most demos can only show one. Because we own the data and generate creative output, we show both — and run them live.

ANALYTICS

Deterministic · ground truth

Compute the true answer straight from the DB and check the agent automatically. Includes an injected-error scenario to measure recovery.
